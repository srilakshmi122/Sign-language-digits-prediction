# 🤟 Sign Language Digit Prediction Using Machine Learning

## 📌 Project Overview

Sign Language Digit Prediction is a Machine Learning project that predicts hand gestures representing numbers (0–9) using image classification techniques.

The main objective of this project is to recognize hand gestures from images and convert them into their corresponding numerical digits. This project demonstrates how Machine Learning and image processing can be used to support sign language recognition.

## 🎯 Objectives

- To recognize hand gestures representing digits from 0 to 9.
- To build a Machine Learning model for image classification.
- To preprocess hand gesture images for better prediction.
- To predict the digit based on the input hand gesture image.

## 📂 Dataset

The dataset contains images of hand gestures representing numbers from **0 to 9**.

- Input: Hand gesture images.
- Output: Predicted digit (0–9).
- Dataset: Images organized into folders based on their respective digit classes.

## 🛠️ Technologies Used

- Python
- Machine Learning
- NumPy
- Pandas
- Matplotlib
- OpenCV
- Scikit-learn
- Jupyter Notebook

## ⚙️ Project Workflow

1. **Data Collection:** Collect hand gesture images representing digits from 0 to 9.
2. **Data Preprocessing:** Resize images, convert them into suitable formats, and prepare the data.
3. **Model Training:** Train the Machine Learning model using the prepared dataset.
4. **Model Testing:** Test the trained model using new hand gesture images.
5. **Prediction:** Predict the corresponding digit based on the input image.

## 📊 Project Outputs

The model provides two possible outputs:

1. **Predicted Digit:** Displays the recognized numerical digit (0–9).
2. **Prediction Result:** Displays the final classification result.
